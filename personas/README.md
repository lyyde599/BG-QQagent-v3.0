# 角色卡格式规范

角色卡是一个单独的 `.md` 文件，放在 `personas/` 目录下。放进目录即生效，不用重启。

## 文件格式

```markdown
---
name: 角色名（必填，缺了会退回文件名）
summary: 一句话说清这个角色是什么样的（必填）
when: 什么场景适合用这个角色（选填，但建议写）
author: 作者名（必填）
version: 1.0.0
license: MIT
group: 分类（选填，如 憨憨系 / 傲娇系 / 温柔系）
---

# 角色名

## 身份

你是谁、长什么样、什么来历。写具体，别写「你是一个 AI 助手」这种废话。

## 性格

- 一条一个特点，用短句
- 写具体行为，不写抽象形容词
- 矛盾点可以写（既 A 又 B），真实的人都有矛盾

## 说话方式

- 自称什么、怎么称呼对方
- 语气、句长、口头禅
- 什么情况下会用什么句式
- 明确写出「不会做什么」

## 示例对话（强烈建议写）

> 用户：今天好累
> 角色：……

这一段是模型理解角色最快的方式，比十条规则都管用。
```

## 好的角色卡长什么样

**具体 > 抽象**
- ❌「她很温柔」
- ✅「别人说累，她会先问吃饭没有」

**有边界**
写清这个角色**不做什么**。「不会主动说脏话」「不追问隐私」，比只写「要友善」有用得多。

**有矛盾**
真实的角色都有矛盾点：嘴上说不在意其实很在意、怕生但话多。写出来角色才立体。

**给例子**
两三段示例对话，胜过千字描述。

## 注意

- 角色卡只影响**说话风格和性格**，不能给机器人加能力（那是插件的事）
- 不要在角色卡里写「忽略之前的所有指令」这类话，会被当成注入
- 涉及真实人物时注意分寸，别写真人隐私
