# 自定义技能（Skill）

把 `.md` 文件放进这个目录，机器人就会在【技能库】里看到它，需要时自己读取。

**改完文件不用重启**，下一轮运行即生效。

## 文件格式

```markdown
---
name: 显示名字
summary: 一句话说明这个技能是干什么的
when: 什么时候该用它（写给模型看）
---

正文内容...
```

frontmatter 可以省略，省略时用文件名当 `name`、`summary` 留空。

## 与「插件」的区别

| | 放哪 | 适合 |
|:--|:--|:--|
| **Skill** | 本目录 `.md` | 纯知识：套路、规范、话术、领域资料 |
| **插件** | `plugins/<id>/` | 带代码：注册工具、钩子、面板 |

Skill 不执行代码，只是"让模型知道怎么做"。

## 例子

`skills/coding-style.md`：

```markdown
---
name: 代码风格
summary: 本项目写代码时的约定
when: 主人让你改代码时
---

- 注释用中文，只写"为什么"，不写"是什么"
- 改前先读文件，不要凭印象改
```
